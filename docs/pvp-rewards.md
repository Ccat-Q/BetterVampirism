# BetterVampirism PvP 奖励

## 依赖与范围

- Minecraft `1.21.1`、NeoForge `21.1.243`。
- 必须安装 Vampirism `1.21-1.10.12`。
- BetterVampirism 是独立附属模组；不会包含或替换 Vampirism。

## 有效击杀

奖励仅在服务端生效，并且双方都必须是生存或冒险模式的真实玩家。近战、弓箭、弩箭、三叉戟等由玩家负责的投射物击杀都有效；宠物、陷阱、环境伤害、创造/旁观玩家、无阵营玩家和同阵营玩家均无效。

吸血鬼击杀猎人、或猎人击杀吸血鬼时，击杀者若未达到所属阵营的最高等级，会直接提升一级。该 PvP 途径替代本次原版祭坛或训练师材料升级，不额外创建经验条或任务。

## 掉落与反刷

物品在受害者死亡位置公开掉落：

| 击杀者 | 受害者 | 默认掉落 |
| --- | --- | --- |
| 吸血鬼 | 猎人 | 人类心脏 ×1 |
| 猎人 | 吸血鬼 | 吸血鬼尖牙 ×1、普通血瓶 ×1、吸血鬼血瓶 ×1 |

同一击杀者和受害者 UUID 组合默认有 120 秒真实时间冷却。冷却期内不升级也不掉落；该记录只在内存中保存，因此服务器重启会清空冷却。

## 服务端配置

首次启动会生成 `config/bettervampirism-server.toml`。可调整：

- `pairCooldownSeconds`：同一玩家组合的冷却秒数。
- 每种奖励的 `enabled`、`count`、`chance`：启用状态、数量和 0.0–1.0 概率。

配置由服务器控制，客户端无需单独设置。

## 验收边界

GitHub Actions 在推送到 `main`、向 `main` 提交 PR 或手动触发时使用 Java 21 执行 `./gradlew build` 并上传 JAR。构建成功只证明依赖解析、编译和单元测试通过；仍须在实际 NeoForge 服务器中同时安装指定 Vampirism JAR，验证 PvP 阵营、掉落、冷却与客户端同步。
