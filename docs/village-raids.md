# 村庄袭击范围与钟状态

## 缩小村庄袭击判定范围

BetterVampirism 不会复制或覆盖 Vampirism 的袭击状态机。村庄范围由 Vampirism 服务端配置
`config/vampirism-balance.toml` 的 `maxTotemRadius` 决定，原值为 `100`。将其改为下面的值后重启服务端：

```toml
maxTotemRadius = 64
```

这会让距离图腾超过 64 格的床、工作站等 POI 不再归入该图腾的村庄；袭击单位生成、计数和结算区域也会相应缩小。
已有的大村庄需在重启后让图腾完成一次状态刷新。

## 敲钟查看未解决单位

袭击进行中，玩家右键敲击位于当前图腾村庄附近的钟，会在聊天栏看到：

```text
袭击未解决单位 - 攻击方 吸血鬼 ×2；防守方 猎人 ×1
```

统计范围与 Vampirism 的当前村庄袭击范围完全一致，只统计存活且未被 Vampirism 标记为忽略袭击的单位。没有袭击时会明确提示。

此提示只在服务端运行；客户端不需要单独安装 BetterVampirism。
